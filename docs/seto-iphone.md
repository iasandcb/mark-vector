## 세토 iPhone 실시간 입력

세토 앱의 mark-vector 네이티브 편집창은 로그인 세션으로
`/ws/documents/{project_id}/{conv_id}/{filename}?write=1`에 연결합니다.
아이폰이 유일한 작성자이며 전체 텍스트 스냅샷을 약 60ms 간격으로 합쳐 전송합니다.
서버는 파일 저장을 마친 뒤 작성자에게 `{type:"ack", sequence, version}`을 보내고,
같은 문서를 열어 둔 웹 편집기에 `{type:"update", content, version}`을 보냅니다.
맥에서는 같은 문서를 열어 두면 편집기와 마크다운 미리보기가 바로 갱신됩니다.
이미 열어 둔 웹 탭은 새 코드를 받도록 한 번 새로고침해야 합니다.

구독 연결은 같은 경로에서 `write=1` 없이 열고, 현재 저장 상태를 `ready` 메시지로
받습니다. 재연결도 파일에서 다시 읽으므로 서버 재시작 후에도 저장 내용이 유지됩니다.
새 연결과 각 메시지에서 로그인 세션을 검사하고 외부 Origin을 거부합니다.
문서 내용은 공개 라이브·안경 ambient 채널에 보내지 않습니다.

아이폰은 한 번에 한 스냅샷의 저장 완료를 기다리고 그 사이 입력을 최신 내용으로
합칩니다. 연결이 끊기면 로컬 입력을 유지한 뒤 재연결 시 최신 내용을 다시 전송합니다.
문서당 작성자 하나만 허용하며 여러 작성자의 병합은 지원하지 않습니다. 맥에 미저장
수정이 있으면 웹 편집기는 실시간 스냅샷을 덮어쓰지 않습니다. 기존 HTTP 폴링도
연결 중단 시 보조 경로로 남아 있습니다.
