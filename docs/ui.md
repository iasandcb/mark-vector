## 화면

화면은 3단 세로 split 뷰입니다.

- **왼쪽**: `data/projects/`를 반영한 **프로젝트 → 폴더 → 문서** 트리([프로젝트 · 폴더 · 문서](documents-and-storage.md#프로젝트-폴더-문서) 참고). 폴더는 하위 폴더를 가질 수 있고, 디스크에는 `conversations/<폴더ID>/`가 프로젝트 폴더 안에 평평하게 있으며 중첩은 `meta.json`의 `parent_id`입니다. 폴더 제목을 비워 두면 첫 사용자 메시지의 첫 줄(앞의 `#`은 빼고, 60자까지)로 채워지고, 만들 때 제목을 적거나 폴더 행의 ⋯ 메뉴 ✎로 바꾸면 이후 메시지로 다시 바뀌지 않습니다.
- **가운데**: 왼쪽에서 선택한 문서를 편집하는 에디터. 문서를 열면 수식 표기(LaTeX/AsciiMath/하이브리드)를, 보낼 수 있는 문서면 거기에 프로바이더/모델/사고 수준/맥락까지 고르는 작은 툴바가 있습니다(상단 버튼 줄을 한 줄로 유지하려고 평소에는 접혀 있고, 오른쪽 끝 ⚙로 엽니다)(프로바이더/모델/사고 수준/맥락은 폴더가 아니라 메시지 단위 설정이고, 수식 표기는 문서의 directive를 따릅니다 — [모델 목록 & 사고 수준](models.md#모델-목록-사고-수준) 참고).
- **탭**: 왼쪽 트리·빠른 열기·링크 등으로 문서를 열면 항상 새 탭으로 열립니다(이미 열린 문서면 그 탭으로 이동). 탭이 둘 이상이면 편집기 위에 탭 줄이 나타나고, 저장하지 않은 탭은 ● 표시가 붙습니다. 탭을 옮겨 다녀도 저장하지 않은 내용은 그대로 남고, 저장된 탭은 돌아올 때 서버에서 최신 내용을 다시 읽습니다. 탭을 가로로 끌면 순서가 바뀌고, 놓을 자리에 표시줄이 나옵니다. 조금 움직인 클릭은 여전히 그 탭으로 전환되고, 닫기 버튼을 누르는 것은 드래그가 아닙니다. ⌥[ / ⌥](다른 OS는 Alt) 이전·다음 탭, ⌥⇧[ / ⌥⇧]로 현재 탭을 왼쪽·오른쪽으로 옮기기, ⌥W 탭 닫기, ⌥O 현재 탭만 남기고 모두 닫기(탭을 오른쪽 클릭하면 그 탭만 남기기), 가운데 클릭으로도 닫습니다(⌘W·⌃Tab은 브라우저가 쓰므로 쓸 수 없음). 끌어 바꾼 순서를 포함한 열린 탭 목록은 새로고침 후에도 유지됩니다. 분할 보기의 오른쪽 칸에는 탭이 없습니다.
- **오른쪽**: 가운데 편집 중인 내용의 실시간 마크다운 미리보기.

가운데 에디터의 **대화** 버튼을 누르면 현재 편집 중인 내용이 사용자 턴으로 전송되고, LLM 응답이 스트리밍되어 그 파일의 어시스턴트 섹션으로 붙습니다. 초안을 연 채 보내면 그 파일이 그대로 공식 턴이 되고, 이미 완성된 턴에서 보내면 새 `NNNN.md`가 트리에 나타납니다.

문서가 열려 있을 때 점프 키(맥은 `⌃`, 그 외는 `Alt`)를 잠깐(약 0.35초) 누르고 있으면 트리의 문서에 `⌃1`~`⌃9` 배지가 붙고, 그 번호를 누르면 해당 문서가 바로 열립니다 — 1~3은 최근에 연 문서(지금 열린 문서는 빼서, 1은 직전 문서), 4~9는 같은 폴더의 나머지 문서입니다. 그 밖의 문서는 퀵 오픈(`⌘P`/`⌘K`)으로 찾습니다. (`⌥↑`/`⌥↓`는 편집기의 줄 위/아래로 옮기기 키라 앱 단축키로 쓰지 않습니다.)

화면 폭이 700px 이하(휴대폰)일 때는 3단이 아니라 화면 아래 탭(📁 목록 / ✏️ 편집 / 👁 미리보기)으로 한 번에 한 화면만 보여주고, 글자 크기와 버튼/터치 영역을 키워서 좁은 화면에서도 눈에 편하게 읽고 누를 수 있게 했습니다. 문서를 선택하면 자동으로 편집 탭으로 전환됩니다.

- **백엔드**: Python (FastAPI)
- **프론트엔드**: 바닐라 HTML / CSS / JS (빌드 도구, 프레임워크 없음)
- **LLM 프로바이더**: Anthropic, OpenAI, ChatGPT 플랜 (전환 가능한 구조. ChatGPT는 API 키 대신 플랜 로그인)
- **수식 렌더링**: KaTeX (LaTeX) + [asciimath-markdown](https://github.com/iasandcb/asciimath-markdown) (AsciiMath2 → LaTeX 변환은 그 안의 asciimath-parser). AsciiMath2 표준과 그 표준을 구현한 LaTeX → AsciiMath2 변환 파이썬 패키지는 별도 저장소 [asciimath2](https://github.com/iasandcb/asciimath2) (PyPI `asciimath2`) 참고.

## 대화로 옆 문서 작성·수정하기

분할 보기에서 **왼쪽은 대화, 오른쪽은 문서**로 두고, 대화에서 요청해 오른쪽 문서를 쓰거나 고칠 수 있습니다. 예: 왼쪽 `001.md`에서 "draft에 있는 질문을 바탕으로 추가 질문 10개를 추가해줘"라고 보내면 오른쪽 `draft.md`에 10개가 들어갑니다.

- 오른쪽에 문서가 열려 있으면 왼쪽 상단에 **✏️ 버튼**이 나타납니다. 켜져 있는 동안(기본) 보내는 메시지에 오른쪽 문서의 현재 내용(저장하지 않은 수정 포함)이 함께 가고, 모델은 요청이 작성·수정일 때만 문서를 고칩니다. 문서에 대한 질문에는 그냥 답합니다. 끄면 문서를 보내지 않습니다.
- 수정은 답이 오는 대로 오른쪽 문서에 **바로 적용**되지만 **저장하지 않은 변경**으로 남습니다. 저장은 직접 합니다. 방금 바뀐 곳은 선택된 채로 보이고, 오른쪽 위의 띠에 몇 곳이 바뀌었는지와 **되돌리기**가 나옵니다(그 메시지로 바뀐 것을 한 번에 원래대로).
- 모델은 답 안에 수정 블록(찾을 글 → 바꿀 글, 끝에 덧붙이기, 문서 전체 다시 쓰기)을 적고, 앱이 그것을 문서에 적용합니다(`frontend/static/js/doc-edits.js`, 백엔드의 `_target_document_prompt`). 도구 호출이 아니라 글로 된 약속이라 ChatGPT 플랜·OpenAI·Claude·Hermes 어느 프로바이더에서나 같습니다. 찾을 글이 문서에 없으면 그 블록은 건너뛰고 띠에 "찾지 못함"으로 알립니다.
- 대화 문서에는 수정 블록 원문이 그대로 남고, 미리보기에서는 "✏️ 옆 문서를 고쳤습니다" 한 줄로 줄여 보여 줍니다.
- 문서는 매 메시지에 통째로 함께 가므로 긴 문서일수록 토큰을 더 씁니다(20만 자까지).
- 왼쪽이 `이름.c.md`이고 오른쪽이 같은 폴더의 `이름.md`이면, 오른쪽 창 헤더에도 **발행**과 **𝕏 아티클**이 나타납니다. 둘 다 오른쪽 문서(저장하지 않은 수정 포함)를 대상으로 합니다. 왼쪽 버튼은 왼쪽 문서를 그대로 다룹니다. 그 짝이 아니거나 분할을 닫으면 오른쪽 버튼은 숨고, 단일 창의 발행·아티클은 이전과 같습니다.
