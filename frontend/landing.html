Answer

Rewrite the equation as

(A − λI) v = 0

A non-zero v exists only if the matrix is singular, so

det(A − λI) = 0

What it does주요 기능

Instead of a chat bubble stream, mark-vector keeps a tree of projects, sessions and turns, each turn a plain .md file on disk. 말풍선이 흘러가는 채팅 대신, 프로젝트 → 세션 → 턴의 트리로 정리하고 각 턴을 디스크의 평범한 .md 파일로 저장합니다.

📝

Edit, then send편집하고 보내기

Draft in a full editor with live preview. Every past turn stays an editable document you can revisit and build on.실시간 미리보기가 있는 편집기에서 초안을 쓰고, 지난 턴도 언제든 다시 열어 고치고 이어 쓸 수 있는 문서로 남습니다.

∑

Math that stays readable읽히는 수식

LaTeX in replies can be converted to AsciiMath2 automatically, so the source stays as readable as the rendered KaTeX.답변 속 LaTeX를 AsciiMath2로 자동 변환해, 렌더링된 KaTeX뿐 아니라 원문도 읽기 쉽게 유지합니다.

🔀

Model per turn턴마다 모델 선택

Pick provider, model and reasoning effort per message — ask GPT, follow up with Claude, in the same thread.메시지마다 프로바이더·모델·사고 수준을 고릅니다. 같은 스레드에서 GPT에 묻고 Claude로 이어갈 수 있습니다.

Sign in with ChatGPTChatGPT로 로그인

Instead of pasting an OpenAI API key, you can connect your own ChatGPT plan. mark-vector then sends your OpenAI requests on that plan, within the limits you set in ChatGPT. OpenAI API 키를 붙여 넣는 대신 본인의 ChatGPT 플랜을 연결할 수 있습니다. 그러면 mark-vector는 ChatGPT에서 정한 한도 안에서 그 플랜으로 OpenAI 요청을 보냅니다.

How it works동작 방식

  1. Sign in with your ChatGPT account and approve plan usage on OpenAI's own consent screen.ChatGPT 계정으로 로그인하고 OpenAI 동의 화면에서 플랜 사용을 허용합니다.
  2. OpenAI's models available to your account appear as the ChatGPT provider in the model picker.계정에서 쓸 수 있는 모델이 모델 선택기의 ChatGPT 프로바이더로 나타납니다.
  3. Each reply is streamed from OpenAI's Responses API and saved as a Markdown turn.답변은 OpenAI Responses API에서 스트리밍되어 마크다운 턴으로 저장됩니다.
  4. Track or cap usage anytime in ChatGPT Settings → Usage.사용량은 언제든 ChatGPT 설정 → Usage에서 확인하고 제한할 수 있습니다.

What we do — and don't — access접근하는 것과 하지 않는 것

  • Only the permissions you approve: basic profile (email) and plan usage for model requests.허용한 권한만 사용합니다: 기본 프로필(이메일)과 모델 요청을 위한 플랜 사용.
  • No access to your ChatGPT conversations, memory or other account data.ChatGPT 대화, 메모리 등 다른 계정 데이터에는 접근하지 않습니다.
  • Requests are sent with store: false; your documents live in mark-vector, not in OpenAI's storage.요청은 store: false로 보내며, 문서는 OpenAI가 아닌 mark-vector에 저장됩니다.
  • Tokens are kept server-side in an owner-only file — never in the browser, logs or URLs.토큰은 서버의 소유자 전용 파일에만 보관하며 브라우저·로그·URL에는 남기지 않습니다.
  • Disconnect anytime from ChatGPT settings; signing out also revokes the session.ChatGPT 설정에서 언제든 연결을 끊을 수 있고, 로그아웃하면 세션도 해지됩니다.
